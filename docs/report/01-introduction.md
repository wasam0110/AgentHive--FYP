# Chapter 1 — Introduction of the Project

Status: Draft for supervisor review. Owner of consolidation: Shizza. Technical contributors: all members.

## 1.1 Overview

Agent Hive is a proposed multi-agent customer operations system for a configurable business. It coordinates support, catalog enquiries and resource scheduling through specialized workers and a supervisor. The backend validates proposals and requires customer consent and human approval where applicable before changing project records.

## 1.2 Project objective

Handle multi-intent requests, ground responses in verified business data and retrieved guidance, expose useful action evidence, and compare agent configurations through reproducible evaluation. FYP-I demonstrates the core workflow; the complete research evaluation is planned for FYP-II.

## 1.3 Project scope

One configured business per deployment and synthetic data. Include intake, orchestration, support retrieval, domain proposals, controlled approval/execution and a basic dashboard. Exclude real payments, real network provisioning, voice and commercial multi-tenant SaaS. Proposed architecture is described in ../PRD.md; do not describe planned features as implemented.

## 1.4 Summary

The project aims to coordinate a customer request across business functions while retaining explicit authorization and evidence. Replace planning statements with verified outcomes only after implementation.
