# University formats and submission workflow

originals/ preserves all five supplied files byte-for-byte, including old sample dates and names. These are reference templates, not completed submissions. Do not interpret their sample dates as deadlines.

1. Draft and review Chapters 1–4 under docs/report.
2. Use the report content PDF as the required structure; an editable official report DOCX was not provided. Obtain it from the coordinator, then assemble the reviewed draft in that format.
3. Copy the MoM and fortnightly DOCX files into submissions/private/ for actual entries and signatures. Replace template sample text with real details only.
4. Use docs/planning/gantt-plan.csv as the dated task source for the original Gantt workbook. Preserve workbook formulas and conditional formatting when transferring rows. Planned dates are not actual completion.
5. Obtain the missing registration form, SDG rubric and poster guidelines. The official similarity/AI reports must come from the supervisor's process.
6. Do not submit a blank template or these scaffold files as a completed report. Review, fill missing details, format, and obtain required approvals.

Completed forms, signatures, IDs and screening reports belong in submissions/private/ by default; that folder is excluded from Git. Sharing an entire ZIP also shares ignored files, so check its contents before sending it beyond the team.
